# EZ-CDM

A Daylight UI plugin for WoW: Forever. It shows Daylight UI's Cooldown Manager settings
as plain sentences in the `/cdm` editor, and you change them by clicking words. It needs
Daylight UI 2.2.4 or newer.

## Contributing

Setup, the tests and the rules a change follows are in [CONTRIBUTING.md](CONTRIBUTING.md).
Every pull request runs the test suite on GitHub.
